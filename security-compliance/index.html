IAM & Organizations

  • Service Control Policies (SCPs): Applied at the Organization Root or OU level. Used to globally deny actions (like denying access to unauthorized AWS Regions). SCPs never grant permissions, they only restrict them.
  • Permissions Boundaries: Attached to IAM users/roles. Used to delegate IAM creation rights to developers without allowing them to create a role with admin privileges (prevents privilege escalation).
  • External IDs: Always require an ExternalId when granting cross-account IAM role assumption to a third-party vendor. This prevents the "Confused Deputy" attack.

Vulnerability Management & Secrets

  • AWS Secrets Manager: The premier service for database credentials. Natively supports automatic password rotation via built-in AWS Lambda functions.
  • Systems Manager Patch Manager: Automates OS-level patching for both Linux and Windows fleets using Patch Baselines and Maintenance Windows.
  • Amazon Inspector: Scans EC2 instances and ECR container images for software vulnerabilities (CVEs) and unintended network exposure.
  • AWS Firewall Manager: The only service capable of automatically deploying and enforcing AWS WAF rules across hundreds of accounts in an AWS Organization.
