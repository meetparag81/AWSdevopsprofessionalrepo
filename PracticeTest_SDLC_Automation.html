CodeDeploy & Hooks

  • Lambda / ECS Hooks: BeforeAllowTraffic is used to execute tests (e.g., verifying a DB migration or a Step Function) before sending live requests to the new version.
  • Blue/Green Deployments: Modifies the ECS service definition and shifts traffic via Application Load Balancer target groups (not NLB).
  • Rollback Triggers: Connect CodeDeploy automatic rollbacks to CloudWatch Alarms (e.g., TargetResponseTime metric) for instant mitigation.

Builds & Artifacts

  • CodeBuild Artifacts: Save generated output files (JARs, ZIPs) using the artifacts section in buildspec.yml to pass them to downstream Pipeline stages.
  • CodeArtifact: A fully managed artifact repository. Authenticate EC2 instances via an attached Instance Profile, and run aws codeartifact login in the BeforeInstall hook.
  • Load Testing: To test massive concurrency, use AWS CodeBuild to run heavy load-testing frameworks (like JMeter/Taurus) instead of provisioning EC2 test instances.
