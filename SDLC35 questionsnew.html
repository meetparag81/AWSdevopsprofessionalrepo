CodeDeploy, CodeBuild & CI Features

  • Lambda / ECS Hooks: BeforeAllowTraffic executes tests (e.g., verifying DB) before sending live requests.
  • CodeDeploy ASG Integration: If an ASG scales out, new instances automatically receive the latest successful revision.
  • CodeBuild inside a VPC: To connect to private RDS databases, CodeBuild requires a VPC ID, Subnets, and Security Groups.
  • CodeBuild Caching: Speed up Maven/Node builds by defining an S3 cache path in `buildspec.yml` to avoid internet re-downloads.
  • Test Reporting: CodeBuild natively visualizes JUnit metrics. Configure a reports block in `buildspec.yml`.

Pipelines, Artifacts & CloudFormation

  • CodePipeline Cross-Account: 1) MUST use a Customer Managed KMS Key (CMK) for the artifact bucket. 2) Use cross-account IAM roles.
  • CodeArtifact: A fully managed artifact repository. EC2 authenticates via Instance Profile + aws codeartifact login in `BeforeInstall`.
  • Step Functions in Pipeline: If a test takes over 15 minutes, orchestrate it using an AWS Step Functions action.
  • Stack Policies: JSON docs that prevent unintentional updates (e.g., Update:Replace) to critical resources like RDS.
  • StackSets: Deploy CFN templates across multiple AWS accounts and regions from the management account.
