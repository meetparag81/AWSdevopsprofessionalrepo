CloudFormation & Infrastructure

  • Stack Policies: JSON documents applied to a stack that explicitly prevent unintentional updates/replacements (e.g., Update:Replace) to critical resources like RDS databases.
  • StackSets: The native tool to deploy CloudFormation templates across multiple AWS accounts and regions from a single management account.
  • Step Functions in CodePipeline: If an integration test or manual QA process takes over 15 minutes (Lambda timeout limit), orchestrate it using an AWS Step Functions action natively inside CodePipeline.

Builds & Cross-Account Pipelines

  • CodePipeline Cross-Account: 1) You MUST use a Customer Managed KMS Key (CMK) for the artifact bucket. Default aws/s3 keys cannot be shared. 2) Use cross-account IAM roles.
  • CodeBuild Caching: Speed up massive Maven/Node builds by defining an S3 cache path in your buildspec.yml file to avoid re-downloading internet dependencies.
  • CodeBuild Secrets: Never hardcode passwords. Store them in Secrets Manager or SSM Parameter Store, and reference them natively in the env: secrets-manager section of your buildspec.
