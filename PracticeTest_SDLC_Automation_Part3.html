CodeBuild & CI Features

  • CodeBuild inside a VPC: To connect to private RDS databases or internal APIs, CodeBuild requires you to specify a VPC ID, Subnets, and Security Groups in its project configuration.
  • Test Reporting: CodeBuild natively visualizes JUnit/Cucumber test metrics in the console. You MUST configure a reports block in the buildspec.yml to enable this feature.
  • CodeCommit Approvals: Use Approval Rule Templates to natively enforce that PRs require X number of approvals from specific IAM groups before a merge is permitted.

CodeDeploy, SAM & CloudFormation

  • CodeDeploy ASG Integration: If an ASG scales out after a successful CodeDeploy deployment, the new instance automatically receives the latest successful revision.
  • AWS SAM Deployments: sam build compiles code. sam package uploads artifacts to S3. sam deploy deploys the CloudFormation stack.
  • CFN Drift Detection: Use AWS Config with the cloudformation-stack-drift-detection-check managed rule to continuously monitor for manual out-of-band changes to your CloudFormation stacks.
  • Elastic Beanstalk Traffic Splitting: The only native EB deployment policy that routes a specific percentage of traffic (e.g., 15%) for a specific evaluation time before full cutover is Traffic splitting.
