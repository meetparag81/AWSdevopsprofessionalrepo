Orchestration & Runbooks

  • SSM Incident Manager: Provides native escalation plans and automated runbooks. If the primary on-call engineer misses an SMS/Voice alert, it automatically pages the secondary engineer.
  • EventBridge to Step Functions: For complex, multi-step incident remediations (e.g., isolating an EC2 instance, waiting for a snapshot, then deleting the ENI), use EventBridge to trigger an AWS Step Functions state machine.
  • AWS Config Auto-Remediation: Maps directly to SSM Automation Documents to fix static configuration violations (e.g., automatically encrypting new S3 buckets).

Detection & Diagnostics

  • CloudWatch Anomaly Detection: The only solution for metrics that fluctuate based on the time of day. Generates alarms based on ML-driven historical baselines rather than static numbers.
  • Isolating Compromised Instances: Do NOT terminate a compromised instance during an active forensic incident. Instead, use an automated runbook to attach a restrictive Forensic Security Group (deny all egress, allow ingress only from forensics team) to preserve memory and state.
  • AWS Health Dashboard: Emits events to EventBridge for AWS-managed hardware failures, scheduled EC2 maintenance, or underlying infrastructure degradations.
