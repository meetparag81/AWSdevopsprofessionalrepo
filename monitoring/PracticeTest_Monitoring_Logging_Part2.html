Event Routing & Governance

  • Trusted Advisor Events: Trusted Advisor integrates natively with Amazon EventBridge, allowing you to trigger a Lambda function or SNS based on check results (e.g., cost optimization or security findings).
  • AWS Config & QuickSight: AWS Config continuously records configuration changes into an S3 bucket. You can connect Amazon Athena and Amazon QuickSight directly to this bucket for powerful visual compliance dashboards.
  • AWS Health Events: Used to track AWS-initiated maintenance on resources. Monitor these via EventBridge to automatically push notifications to external endpoints like Slack via Lambda.

Log Analytics & Troubleshooting

  • CloudWatch Metric Filters: Scan incoming CloudWatch logs for specific text patterns (e.g., "Critical" or "Error") to generate numerical metrics, which trigger CloudWatch Alarms -> SNS.
  • VPC Flow Logs & Egress Rules: If an instance cannot reach an external API (like HTTPS port 443), check VPC Flow Logs for REJECT records to confirm if an outbound (egress) security group rule is blocking it.
  • S3 Server Access Logs + Athena: The most cost-effective way to find popular S3 objects (access patterns) is to enable Server Access Logging and query the raw log files in S3 using Amazon Athena.
  • SSM Inventory: Periodically collects instance metadata, including installed packages, and syncs it to S3 automatically for compliance reporting.
