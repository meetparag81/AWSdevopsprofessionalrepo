Governance & Automated Auditing

  • AWS Config for Audits: Config captures the state of your resources. You can create rules (like encrypted-volumes or cloudtrail-enabled) to flag non-compliance.
  • Amazon Macie: Fully managed data security and privacy service that uses machine learning to automatically discover and protect sensitive PII data in S3.
  • Amazon GuardDuty: Intelligent threat detection. Combines CloudTrail, VPC Flow Logs, and DNS logs to flag anomalous behavior or compromised credentials.

Metrics & Logs

  • CloudWatch Anomaly Detection: Dynamically adjusts to historical trends (like day vs. night traffic) so you don't get false positive alerts when traffic naturally dips.
  • Custom Metrics: If a specific application metric is needed (e.g., number of payment refunds), use the AWS SDK (PutMetricData) to push a Custom Metric directly into CloudWatch.
  • EC2 System Log: When an instance completely fails to boot up or SSH fails and SSM is unavailable, viewing the raw System Log from the console is the first diagnostic step.
  • Container Insights: Used on EKS/ECS to capture robust infrastructure metrics (CPU, Memory, Network) per task and per service in near real-time.
