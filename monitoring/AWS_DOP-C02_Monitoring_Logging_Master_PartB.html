Tracing & Logging

  • CloudWatch Logs Insights: Query up to 50 log groups simultaneously to trace cross-service requests.
  • CloudWatch Metric Filters: Turns raw text patterns (or structured JSON) into numerical metrics.
  • AWS X-Ray: Visualizes end-to-end request paths (Service Map). ECS sidecar listens on UDP Port 2000.
  • Metric Archival: Export metrics to S3 via Metric Streams + Firehose to retain for 7 years.
  • Athena & Flow Logs: Export VPC Flow Logs as Parquet with Hive-prefixes to S3 to reduce Athena scan costs.
  • Container Insights: Natively collects CPU/Mem/Network utilization per task on ECS/EKS.

Security & Governance

  • Organization Trails: Enforce CloudTrail across all accounts so local admins cannot disable it. Validate using validate-logs.
  • Config Auto-Remediation: Use Config rules (e.g., encrypted-volumes) tied to SSM Automation for automatic fixes.
  • GuardDuty to Slack: Emits findings to EventBridge -> Lambda -> Slack. (Cannot publish complex JSON to SNS directly).
  • S3 Auditing: Track PUT/GET/DELETE cost-effectively via CloudTrail Data Events.
  • Event Routing: Route events cross-account via a Resource-based policy on the target bus.
  • CloudWatch Synthetics: Create Canaries to simulate user flows; captures UI screenshots if it breaks.
