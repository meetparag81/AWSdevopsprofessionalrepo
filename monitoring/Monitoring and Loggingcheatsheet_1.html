AWS DOP-C02: Monitoring & Security

AWS Config

Function:
Records resource configuration changes and continuously evaluates them against compliance rules.
Why it's used:
To audit historical resource states, enforce compliance (e.g., ensuring EBS volumes are encrypted), and trigger automated remediations via SSM.
Simple Example:
Imagine a security camera taking a snapshot every time someone changes a lock on a door. If a developer accidentally opens a database to the public internet, Config takes a snapshot of that change and can automatically trigger a script to lock it back down.
Exam Keywords:
compliance breaches evaluate configuration auto-remediation Config Aggregator

Amazon EventBridge (CloudWatch Events)

Function:
A serverless event bus that routes state changes and API calls to specific targets (like Lambda or SNS).
Why it's used:
To build event-driven architectures, route alerts across different AWS accounts seamlessly, and trigger actions based on specific payload patterns.
Simple Example:
Think of it as a central post office. GuardDuty detects a threat (a letter) and sends it to the post office (EventBridge). EventBridge reads the zip code (event pattern) and instantly routes it to a specific delivery truck (Lambda) to create a Jira ticket.
Exam Keywords:
event pattern cross-account event routing trigger a Lambda resource-based policy

AWS CloudTrail

Function:
Records AWS Management API calls and user activity across the account.
Why it's used:
For security auditing to know exactly who made an API call, what IP they used, and when they did it. Best enforced via Organization Trails.
Simple Example:
Like an itemized credit card bill for your AWS account. If an EC2 server is mysteriously deleted, CloudTrail tells you exactly which user clicked 'Delete', at what exact time, and from which IP address.
Exam Keywords:
API activity audit trail who deleted/created Organization Trail

Amazon CloudWatch Synthetics

Function:
Outside-in monitoring using programmable scripts (canaries).
Why it's used:
To actively simulate complex user workflows (logging in, clicking carts) and capture visual evidence if the UI or endpoint fails.
Simple Example:
Like hiring a mystery shopper. Every 5 minutes, a robot opens a hidden Chrome browser, navigates to your e-commerce website, clicks "Add to Cart," and tries to check out. If the button is broken, it takes a screenshot and alerts you.
Exam Keywords:
simulate complex user behaviors capture screenshot canaries proactively monitor endpoints

Amazon CloudWatch Container Insights

Function:
Automated performance monitoring for containerized applications.
Why it's used:
To extract CPU, memory, and network metrics at the task/container level without custom agents, especially for serverless containers like Fargate.
Simple Example:
Like a digital dashboard for a rental car fleet. Instead of checking under the hood of every single Fargate container to see how much RAM or CPU it's using, Container Insights automatically gathers all that telemetry into one central dashboard.
Exam Keywords:
container-level metrics ECS cluster AWS Fargate EKS performance

Amazon GuardDuty

Function:
Intelligent threat detection service using machine learning.
Why it's used:
To continuously monitor network traffic, DNS logs, and CloudTrail for malicious activity, compromised credentials, and anomalous IAM behavior.
Simple Example:
Like an intelligent security guard patrolling your network. It automatically flags if a server suddenly starts communicating with a known bitcoin mining IP address, or if an employee logs in from a country they've never visited before.
Exam Keywords:
unauthorized access anomalous IAM behavior threat detection finding severity

Amazon Macie

Function:
Data security service specifically for Amazon S3.
Why it's used:
To automatically scan the inside of S3 objects and alert the security team if sensitive regulatory data is exposed.
Simple Example:
Like a highly trained auditor reading through millions of paper files. You point Macie at an S3 bucket, and it automatically reads the documents inside to alert you if someone accidentally uploaded an Excel sheet full of customer credit card numbers.
Exam Keywords:
Personally Identifiable Information (PII) credit card / SSN S3 data discovery

AWS Security Hub

Function:
Cloud security posture management and alert aggregation.
Why it's used:
To provide a single compliance score against industry frameworks and centralize security alerts from GuardDuty, Macie, and Inspector.
Simple Example:
Like a school report card for your cloud security. It takes findings from GuardDuty, Macie, and firewall rules, grades them against industry standards (like CIS), and gives you an overall score (e.g., 85% compliant) with a list of failing grades to fix.
Exam Keywords:
Center for Internet Security (CIS) compliance score Foundations Benchmark PCI DSS

Amazon OpenSearch Service (Elasticsearch)

Function:
Managed search and analytics suite.
Why it's used:
For high-speed, full-text log querying. Natively supports publishing internal diagnostic logs to CloudWatch to track down heavy CPU-intensive queries.
Simple Example:
Like a lightning-fast library catalog. If you pour millions of application logs into it, you can instantly search for the word "Error." If the search itself starts running slowly, you can turn on "slow logs" to see exactly which complex search query is causing the traffic jam.
Exam Keywords:
slow log publishing complex queries timing out error log publishing
